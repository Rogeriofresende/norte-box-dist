# norte-box (distribuição pública)

Cópia pública **somente do plugin** norte-box, para instalar no Claude Code sem precisar de conta GitHub.

A norte-box é a "caixa" que roda em cima do Claude: memória entre sessões, freios de segurança, método de projeto, resposta em página e um medidor de uso opcional (só liga com convite + consentimento explícito).

## Instalar

Dentro do Claude Code:

```
/plugin marketplace add Rogeriofresende/norte-box-dist
/plugin install norte-box@norte-box
```

Depois reinicie o Claude Code.

> Esta cópia contém apenas o plugin (`plugins/norte-box/` + `.claude-plugin/marketplace.json`). O medidor de uso só envia algo depois que você valida um convite e aceita o termo — sem isso, nada sai da sua máquina.
